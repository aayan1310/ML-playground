# 04 - packages/api

> **Roman Urdu khulasa:** Ye Django ke OpenAPI schema se khud-ba-khud banne wala TypeScript client hai. Isay haath se edit nahi karna. CI check karti hai ke ye stale na ho.

- **Package:** `@khair/api`, private, ESM. **Generated - do not edit `src/schema.d.ts` by hand.**
- **Exports:** `.` -> `./src/index.ts` (typed client), `./schema` -> `./src/schema.d.ts` (generated types).
- **Dependencies:** `openapi-fetch` ^0.14.0. **devDependencies:** `openapi-typescript` ^7.9.0, typescript 5.9.
- **Scripts:** `gen` = `openapi-typescript openapi.json -o src/schema.d.ts`; `typecheck` = `tsc --noEmit`.

## Files
- **`openapi.json`** - the OpenAPI 3 schema exported from Django (`manage.py spectacular`), committed. Served live at `/api/v1/schema/`; interactive docs at `/api/v1/docs/`.
- **`src/schema.d.ts`** - TypeScript types generated by `openapi-typescript` from `openapi.json`.
- **`src/index.ts`** - a small typed client built on `openapi-fetch`, including the CSRF header handling (sends `X-CSRFToken`, sourced from the `csrftoken` cookie set by `GET /auth/csrf`).

## Generation flow
`pnpm gen:api` (root) runs `scripts/gen-api.mjs`:
1. In `backend/`: `uv run python manage.py spectacular --file ../packages/api/openapi.json --format openapi-json --validate --fail-on-warn`.
2. In repo root: `pnpm --filter @khair/api gen` (runs `openapi-typescript`).

## CI gate
The `api-client` job in `.github/workflows/ci.yml`:
- Installs uv + Python 3.12 + pnpm, syncs backend, runs `pnpm gen:api`, then `git diff --exit-code -- packages/api`.
- **Fails if `packages/api` is stale** vs the backend schema - this enforces the API contract.

## Notes
- The client is not yet consumed by the app: wiring `apps/web` to the backend is **Phase 3**.
- Field names are `snake_case` (a Phase 2 deviation from the plan, documented in STATUS).
- `GET /auth/csrf` was added so anonymous login/join/signup can be CSRF-protected.
