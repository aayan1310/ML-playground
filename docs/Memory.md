# ML Playground — Project Memory

## Project Overview

An educational web game teaching kids how machine learning works. Students never upload images; they pick from a fixed set of 60 bundled cat/dog images (30 cat, 30 dog), sort them into "cat" and "dog" boxes (labeling, can make mistakes), press **Train**, and test the model on unseen images with prediction + confidence score.

**Stack**: Static browser-only frontend (Vite 8.3 + React 19.2) + FastAPI backend (scikit-learn LogisticRegression). No torch in browser, no server-side ML at inference time. Precomputed ResNet18 embeddings (512-dim L2-normalized) shipped as JSON files.

## Data Pipeline (Run Once, Then Export)

1. `python prep/prepare_dataset.py` — needs torch. Downloads Oxford-IIIT Pet, picks 30 cat + 30 dog (seed 42), resizes ≤512px long side, writes `prep/data/images/` + `manifest.json` (22 train / 8 test per class). Cross-checks binary label vs filename capitalization rule.
2. `python prep/compute_embeddings.py` — needs torch. ResNet18 (ImageNet weights, `model.fc = Identity`), standard preprocessing, `eval()` + `no_grad()`, L2-normalized, writes `embeddings.npy` in manifest order.
3. `python prep/export_browser_data.py` — numpy only. Shuffles ids (seed 42) → opaque `img_001…img_060`, shuffles train/test (seed+1) so classes interleave. Writes `public/ml-playground/` (images + dataset.json only); `labels.json` + `embeddings.json` go to `ml-game-backend/data/` — **never to public**.
4. `python prep/evaluate_offline.py` — numpy + sklearn. Reference LogisticRegression (C=10, lbfgs, l2, max_iter=1000): perfect labels, train-size sweep, labeling-mistake sweep (0–30%), confidence on correct vs wrong. `--json-out docs/evaluation-results.json`.

## Backend API (FastAPI, `ml-game-backend/app/main.py`)

| Endpoint | Purpose |
|----------|---------|
| `GET /health` | `{"status":"ok"}` |
| `GET /api/level/:id/setup` | Level config + label-free test images (ids + URLs) |
| `POST /api/level/:id/pool` | Stage pool: 10 candidates/category, shuffled mixed list, fixed per session |
| `POST /api/level/:id/train` | Validates choices, **no model on wrong labels** (`wrong_labels` 400), trains fresh LR |
| `POST /api/level/:id/predict` | Predict one test image (max 3 distinct per model, test-pool only) |
| `POST /api/level/:id/reveal` | True label + match (only after predict for same model+image) |

**Error envelope**: `{"code": "...", "detail": ...}` (snake_case codes, HTTP status per `docs/data-contract.md` section 4).

**Key constants in `ml.py`**: `MODEL_C = 10.0`, `MODEL_MAX_ITER = 1000`, `MODEL_STORE_CAP = 500` (FIFO eviction).

## Frontend Game Flow (`ml-game-frontend/src/screens/Stage2.jsx`, player-facing Stage 2; was Stage1.jsx)

### Phases
1. **Loading** → fetch `/setup` + `/pool`
2. **Sorting** — drag/tap 6 pictures (3 cat, 3 dog) into boxes; validation on Train
3. **Training** — `TrainSequence` component (portal to body):
   - Teacher praise → calls Robot → Robot scans (beam animation) → Teacher explains → Continue
4. **Predicting** (3 rounds per stage):
   - Pick test image → **Ask model** (single panel button)
   - Robot slides in from bottom-right, speaks prediction + confidence meter
   - **Reveal answer** (same button) → Teacher slides in from bottom-left, reveals true label (right/wrong styling)
   - **Make next prediction** (same button) → reset, used image marked
5. **Complete** — summary score + lesson

### Character Positioning (Fixed Viewport Edges)
- **Robot**: bottom-right (`right: clamp(8px, 2vw, 24px)`), bubble tail points **right** (`.teacher-bubble.predict-bubble--robo::before { right:-9px; border-top+border-right }`)
- **Teacher**: bottom-left (`left: clamp(8px, 2vw, 24px)`), bubble tail points **left** (base `.teacher-bubble::before`)
- Both rendered via `createPortal(..., document.body)` to escape `.game-frame` `backdrop-filter` containing block
- Z-index 65 (above panel, below TopControls 100)
- Portrait/narrow: shrink hard, keep side-by-side, button `min-width: min(180px, 58vw)`

### Single Persistent Panel Button (`.predict-progress-btn`)
Label/action cycles:
- `ready` + picked → **"Ask model"**
- `robo` step → **"Reveal the answer"** (gated by `charReady` after 620ms entrance)
- `teacher` step → **"Make next prediction"** (gated by `charReady`)
- Disabled during in-flight requests, before pick, before character settles

### i18n (`src/i18n.js`)
- Languages: `en` (default), `ru` (Roman Urdu draft), `ur` (Urdu draft)
- `LANGUAGE_SELECTOR_ENABLED = false` (English-only for now)
- Placeholders: `t('key', {name: value})`
- All three dictionaries kept in sync (new keys added for prediction flow)

## Evaluation Baseline (`docs/evaluation.md`)

Classifier: sklearn `LogisticRegression(C=10, lbfgs, l2, max_iter=1000)` on 512-dim ResNet18 embeddings.

| Scenario | Mean Test Acc | Min Test Acc | Conf(Correct) | Conf(Wrong) |
|----------|---------------|--------------|---------------|-------------|
| Perfect labels (22/class) | 100% | 100% | 87.3% | n/a |
| 25% wrong labels (22/class) | 87.8% | 62.5% | 72.9% | 61.2% |
| 3/class clean | 98.5% | 75.0% | 65.6% | 55.0% |

**C=10 chosen**: accuracy ≈ C=1, confidence gap widened (6–24 pts), sub-0.70 share collapsed (62.5% → 0% at n=22 clean).

## Constraints & Rules

- **No student uploads** — only pre-bundled 60 images
- **No labels in browser** — `labels.json` is never fetched; true labels come only from `POST /reveal` after a predict
- **No torch/server ML in browser** — embeddings precomputed, LR runs in FastAPI
- **Opaque ids everywhere** — `img_001…img_060` never reveal class
- **Single worker** — in-memory model store (500 cap), no shared state
- **No new deps without approval** — Vite, React, FastAPI, sklearn, numpy only
- **No commits unless asked** — changes stay uncommitted
